# Фурӯғи илму дониш

Сайт программы поддержки учителей математики в регионах Таджикистана.
Исполнитель: ОБО «Пешрафт».

Сайт состоит из одного файла, `index.html`, и публикуется через GitHub Pages.

Формы пока открывают письмо на info@peshraft.charity. Чтобы заявки приходили
через Formspree, вставьте адрес формы в `window.PESHRAFT_FORM_ENDPOINT`
в начале `index.html`.
